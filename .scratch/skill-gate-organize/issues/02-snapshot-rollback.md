# 02 — Core + 存储:快照与回滚

**What to build:** 每次整理会话开始前可对场景树打快照并可一键回滚。快照 = catalog 整树 + 本批技能文件变更(新增技能名清单、被覆盖技能的原文件备份);上传与一键整理两个槽位各自独立、各自只保留最近一份,持久化于仓库数据目录;回滚:整理槽位=仅还原 catalog;上传槽位=还原 catalog + 删除本批新增技能文件 + 恢复被覆盖技能原文件;回滚返回受影响内容清单。

**Blocked by:** None — 可以立即开始

**Status:** ready-for-agent

- [ ] 打快照后修改场景树(建/删/改场景、挂/解链技能),回滚后场景树与快照时完全一致(整树还原)。
- [ ] 上传槽位回滚:本批新增技能的文件被删除、被覆盖技能的原文件被恢复;整理槽位回滚不触碰任何技能文件。
- [ ] 两槽位互不干扰:任一槽位新快照不覆盖另一槽位;各自保留最近一份(第二次快照覆盖第一次)。
- [ ] 快照持久化,重启后可读;回滚操作与写锁/原子写协同,不产生半写状态。
- [ ] 回滚响应报告受影响内容(还原/删除/恢复的技能与场景)。
