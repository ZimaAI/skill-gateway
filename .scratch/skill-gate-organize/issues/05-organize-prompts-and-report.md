# 05 — Host:整理提示词与报告

**What to build:** 三种模式的整理提示词与报告提取:自动分类(把本批上传技能归入合适场景,无合适则新建含 name+详细描述的场景,可多挂并说明理由)、一键整理(整树:澄清边界、删除多余场景、归类未分类、补写场景描述;报告含冲突/重复清单)、冲突检测(只读,明确禁止修改,报告 ②内容高度相似 ③场景语义重叠 ④挂载过散);提示词嵌入完整场景摘要(name+description+直接技能名)与未分类列表,技能全文由 Agent 经网关 browse/load 按需深读;会话结束后提取结构化整理报告(改动摘要+冲突/重复清单+覆盖清单)并持久化最近一份。

**Blocked by:** 01 — 上传只收集技能 + 未分类查询;03 — skill_organize 组织工具;04 — 整理会话机制
