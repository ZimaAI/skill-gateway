# 04 — Host:整理会话机制

**What to build:** host 侧整理会话启动器:用宿主 API 创建独立顶层会话(非 subagent 身份)、注入整理提示词、等待 Agent 完成;会话完成后保留在 GUI 侧边栏(不销毁),固定命名("技能整理 #时间"式);同一仓库同一时间只允许一个整理会话,新触发被拒并提示;会话开始前按槽位打快照;会话被打断/失败时保留现场与快照,不自动回滚。先以最小提示词做冒烟验证(会话出现、Agent 跑完、会话留存、可打开)。

**Blocked by:** 02 — 快照与回滚

**Status:** ready-for-agent

- [ ] 触发后 GUI 侧边栏出现新会话(普通对话形态),首条消息即整理提示词,标题按命名约定生成。
- [ ] Agent 在会话内正常运行完整循环并完成;完成后会话保留、可打开查看、可继续对话。
- [ ] 同一仓库第二个触发被拒绝并返回明确提示;会话结束后互斥解除。
- [ ] 会话开始前自动按对应槽位打快照(冒烟期即可验证)。
- [ ] 打断会话后:已完成修改保留、快照仍在,不自动回滚。
- [ ] 会话身份为独立顶层会话(会话列表可见、非 subagent 隐藏状态)。
