# 06 — Host + 路由:上传新流程接线

**What to build:** 上传与预览路由切到"仅收集技能"语义:预览返回技能列表、逐条校验原因、覆盖/忽略清单,不再返回任何场景信息;上传成功=技能落盘 + 打上传槽位快照 + 自动开启分类整理会话;若已有整理会话在运行则拒绝上传后的自动开启并提示;上传响应含覆盖清单。

**Blocked by:** 01 — 上传只收集技能 + 未分类查询;05 — 整理提示词与报告

**Status:** ready-for-agent

- [ ] 上传路由返回技能视角结果(技能列表、覆盖清单、忽略清单),不含场景创建/复用信息。
- [ ] 预览路由同样为技能视角,任一技能无效时整体拒绝并逐条给原因。
- [ ] 上传成功后自动开启分类会话(会话可见、命名规范);开启失败(如互斥被占)时返回明确提示。
- [ ] 上传成功后上传槽位快照已就绪,可执行上传回滚。
- [ ] 旧"场景树导入"路由语义完全移除(不再接受/响应场景信息)。
