# 设计规范文档 design.md

## 一、设计原则
本项目采用「简约清爽、轻量化科技感」的设计语言，以 4px 为基础栅格单位，全项目统一色值、字号、间距与组件规则，保证多页面视觉一致性。所有新页面开发必须严格遵循本规范。

---

## 二、配色体系
### 1. 主色体系
| 色值类型 | 色值 | 适用场景 |
|---------|------|----------|
| 主色-标准 | `#165DFF` | 品牌Logo、激活态、高亮图标、选中文字、主操作文字 |
| 主色-浅背景 | `#E8F3FF` | 选中态背景、次要按钮背景、激活项底色 |
| 主色-渐变 | `linear-gradient(135deg, #7B9CFF 0%, #9DB8FF 100%)` | 发送按钮等核心操作按钮背景 |

### 2. 功能辅助色
| 类型 | 色值 | 适用场景 |
|------|------|----------|
| 成功色 | `#00B42A` | 成功提示、校验通过、正向状态 |
| 警告色 | `#FF7D00` | 警告提示、风险提醒 |
| 错误色 | `#F53F3F` | 错误提示、校验失败、危险操作 |
| 信息色 | `#165DFF` | 信息提示、普通通知 |

### 3. 中性色（背景/文字/边框）
| 层级 | 色值 | 适用场景 |
|------|------|----------|
| 主背景色 | `#FFFFFF` | 页面主内容区、卡片底色 |
| 次级背景色 | `#F7F8FA` | 侧边栏、表头、悬浮背景 |
| 悬浮/Hover背景 | `#F2F3F5` | 列表项hover、按钮hover底色 |
| 一级文字色 | `#1D2129` | 页面标题、重点正文、激活菜单 |
| 二级文字色 | `#4E5969` | 普通正文、菜单常态、表单内容 |
| 三级文字色 | `#86909C` | 辅助说明、置灰文字、提示文字 |
| 四级文字色 | `#C9CDD4` | 禁用文字、水印、占位符 |
| 常规边框色 | `#E5E6EB` | 输入框常态、卡片边框、分割线 |
| 淡边框色 | `#F2F3F5` | 轻量分割、容器内部分隔 |

## 三、字体规范
### 字体栈
全局使用无衬线系统字体，保证跨平台一致性：
```
-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, "PingFang SC", "Microsoft YaHei", sans-serif
```

### 字号字重规范
| 层级 | 字号 | 字重 | 行高 | 适用场景 |
|------|------|------|------|----------|
| 页面大标题 H1 | 24px | 600 (Semibold) | 1.4 | 页面主标题、空状态主标题 |
| 模块标题 H2 | 18px | 600 | 1.4 | 弹窗标题、卡片标题、分组大标题 |
| 次级标题 H3 | 16px | 500 (Medium) | 1.5 | 侧边栏分组标题、列表组标题 |
| 正文-常规 | 14px | 400 (Regular) | 1.5 | 菜单文字、输入框文本、表格内容、按钮文字 |
| 正文-强调 | 14px | 500 | 1.5 | 选中菜单项、表单标签、重要信息 |
| 辅助文字 | 12px | 400 | 1.5 | 底部账号、校验提示、分页说明、徽章文字 |
| 最小角标 | 11px | 400 | 1.4 | 小型标签、数字角标 |

## 四、间距体系
所有间距均为 4px 的整数倍，保持视觉节奏统一。

### 1. 容器与页面边距
- 页面左右安全边距：24px
- 卡片容器默认内边距：20px
- 侧边栏左右内边距：16px
- 弹窗内容区内边距：24px

### 2. 模块与区块间距
- 大区块间距（页面主模块之间）：32px ~ 40px
- 中等模块间距：24px
- 小组件间距：16px
- 紧凑元素间距：12px

### 3. 组件内边距
- 大输入框内边距：上下 16px，左右 20px
- 常规按钮内边距：上下 8px，左右 16px
- 轻量功能按钮内边距：上下 6px，左右 12px
- 列表项内边距：上下 10px，左右 12px

### 4. 元素微间距
- 图标与文字间距：8px
- 表单标签与输入框间距：8px
- 校验提示与输入框间距：4px

## 五、通用组件样式规则
### 1. 圆角规则
| 圆角等级 | 数值 | 适用组件 |
|---------|------|----------|
| 全圆角/胶囊 | `999px` | 分段控制器、徽章、标签 |
| 大圆角 | `16px` | 主输入框、大型卡片、搜索框 |
| 中圆角 | `12px` | 弹窗、普通卡片、侧边栏功能按钮 |
| 小圆角 | `8px` | 小按钮、下拉菜单项、分页按钮 |

### 2. 阴影规则
整体采用极淡柔和阴影，保持轻盈感：
- 悬浮阴影（弹窗、卡片hover）：`0 4px 12px rgba(0, 0, 0, 0.06)`
- 常态阴影（输入框、悬浮卡片）：`0 1px 3px rgba(0, 0, 0, 0.04)`
- 无阴影：列表项、侧边栏菜单，仅通过背景色区分状态

### 3. 边框规则
- 常态边框：`1px solid #E5E6EB`
- 聚焦/激活边框：`1px solid #165DFF`
- 禁用边框：`1px solid #F2F3F5`
- 内部分隔：仅使用底部分割线，避免全边框包裹

## 六、核心组件样式规范
### 1. 按钮组件
#### （1）主操作按钮（发送/确认）
- 形态：圆形（图标按钮）/ 圆角矩形
- 背景：主色渐变
- 文字/图标色：`#FFFFFF`
- 字重：500
- Hover态：渐变明度提升，阴影轻微加深
- 禁用态：透明度 40%，光标禁止

#### （2）次要功能按钮（深度思考/智能搜索类）
- 形态：小圆角矩形
- 背景：主色浅背景 `#E8F3FF`
- 文字/图标色：主色 `#165DFF`
- 字号：14px，字重 400
- 无边框设计
- Hover态：背景加深为 `#D4E4FF`

#### （3）幽灵按钮（新建对话/次要操作）
- 形态：中圆角矩形
- 背景：白色 `#FFFFFF`
- 文字色：一级文字色，图标色主色
- 字号：14px，字重 500
- 阴影：极淡常规阴影
- Hover态：背景变为 `#F7F8FA`

#### （4）胶囊分段按钮（模式切换/Tab）
- 容器：1px 浅灰边框，全圆角，白色背景
- 选项：未选中透明背景 + 二级文字色；选中主色浅背景 + 主色文字 + 500 字重
- 切换过渡：0.2s 平滑过渡

### 2. 卡片组件
- 背景：纯白色 `#FFFFFF`
- 边框：`1px solid #F2F3F5`（轻量场景可无边框，仅靠阴影区分）
- 圆角：中圆角 `12px`
- 阴影：常态极淡阴影，hover 时切换为悬浮阴影
- 内边距：默认 20px，紧凑场景 16px

### 3. 侧边导航栏
- 宽度：固定 260px
- 背景：次级背景色 `#F7F8FA`
- 顶部Logo区：高度 60px，左右内边距 16px，垂直居中
- 新建按钮区：上下外边距 16px
- 会话列表：
  - 分组标题：12px、三级文字色、字重 500，上下内边距 8px
  - 列表项：小圆角，上下内边距 10px，左右 12px
  - 常态：透明背景 + 二级文字色
  - Hover态：`#F2F3F5` 背景
  - 激活态：`#E8F3FF` 背景 + 主色文字
- 底部账号区：高度 56px，顶部分割线，左右内边距 16px

## 七、全组件规范细则
### 1. 表格
- 表头：背景 `#F7F8FA`，14px / 500 字重 / 一级文字色
- 表行：行高 48px，垂直居中，白色背景
- 边框风格：无边框表格，仅保留行底部分割线 `#F2F3F5`
- 交互：行 hover 背景变为 `#F7F8FA`
- 斑马纹：可选，偶数行背景 `#FAFBFC`
- 分页：右下角对齐，与表格底部间距 16px

### 2. 弹窗 Modal
- 尺寸：默认宽度 520px，大弹窗 720px，确认弹窗 400px
- 外观：白色背景 + 中圆角 + 悬浮阴影
- 结构规范：
  - 头部：高度 56px，左右内边距 24px，底部淡分割线；标题 18px / 600 字重
  - 内容区：内边距 24px，正文 14px
  - 底部：高度 64px，顶部淡分割线，按钮右对齐，按钮间距 12px
- 遮罩：`rgba(0, 0, 0, 0.4)` 半透明黑色

### 3. 下拉菜单 Dropdown
- 容器：白色背景 + 小圆角 + 悬浮阴影 + 1px 淡边框
- 菜单项：高度 36px，左右内边距 12px，垂直居中
- 交互：常态二级文字色，hover 背景 `#F7F8FA`
- 分割线：淡边框色，上下留白 4px
- 禁用项：三级文字色，无交互反馈

### 4. 分页器
- 按钮尺寸：32px × 32px，小圆角
- 常态：白色背景 + 1px 浅灰边框 + 二级文字色
- 激活态：主色浅背景 + 主色文字 + 无边框
- Hover态：边框变主色 + 文字变主色
- 页码间距：8px
- 总数说明：12px 三级文字色，左对齐

### 5. 表单与校验
- 表单标签：14px 二级文字色，与输入框间距 8px
- 输入框规范：
  - 常态：1px 常规边框 + 大圆角 + 内边距 12px 16px
  - 聚焦态：边框变主色，极淡主色外阴影
  - 禁用态：背景 `#F7F8FA` + 淡边框 + 三级文字色
- 校验提示：
  - 位置：输入框正下方，间距 4px
  - 错误态：12px + 错误色文字，输入框边框同步变错误色
  - 成功态：12px + 成功色文字
- 必填标记：红色 `*` 位于标签前，间距 4px

### 6. 消息提示 Message / Toast
- 轻量Toast：顶部居中弹出，小圆角，半透明白色+模糊背景，内边距 12px 20px
- 通知Notification：右上角弹出，白色背景 + 中圆角 + 悬浮阴影，宽度 320px
- 图标与文字间距：8px
- 自动消失时长：普通提示 3s，错误/警告 5s

### 7. 空状态
- 布局：垂直居中排列：图标 → 标题 → 描述 → 操作按钮
- 图标尺寸：80px ~ 120px，主色浅色调
- 标题：18px / 500 字重 / 一级文字色，与图标间距 16px
- 描述：14px / 三级文字色，行高 1.5
- 操作按钮：与描述间距 24px，使用次要按钮样式

### 8. 步骤条
- 节点样式：圆形，直径 24px
- 状态规则：
  - 未完成：白色背景 + 1px 浅灰边框 + 三级文字色
  - 进行中：主色背景 + 白色文字
  - 已完成：主色背景 + 白色对勾图标
- 连接线：高度 2px，未完成浅灰色，已完成主色
- 步骤文字：14px，位于节点下方，间距 8px
- 步骤间距：均匀分布，最小间距 80px

### 9. 进度条
- 线形进度条：高度 6px，全圆角
- 轨道背景：`#F2F3F5`
- 进度填充：主色纯色或渐变
- 百分比文字：12px 三级文字色，位于进度条右侧
- 环形进度条：线宽 6px，色系规则与线形一致

### 10. 徽章 Badge
- 形态：全圆角胶囊形
- 尺寸规格：
  - 常规徽章：高度 20px，左右内边距 8px，文字 12px
  - 点状徽章：直径 8px，无文字
- 状态配色：
  - 主色徽章：`#E8F3FF` 背景 + `#165DFF` 文字
  - 成功徽章：`#E8FFEA` 背景 + `#00B42A` 文字
  - 警告徽章：`#FFF3E8` 背景 + `#FF7D00` 文字
  - 错误徽章：`#FFECE8` 背景 + `#F53F3F` 文字
  - 默认徽章：`#F2F3F5` 背景 + `#4E5969` 文字
