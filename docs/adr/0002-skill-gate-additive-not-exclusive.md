# v1 网关与 harness 默认技能并存(不吞并)

skill-gate 的动机是"海量技能导致上下文膨胀、触发不准",但 v1 决定网关只管理自己的上传目录、与 harness 默认的 skill 工具/`available_skills` 并存,不隐藏或禁用后者。排他(吞并现有技能)需要 suppress `skill` 工具与 `available_skills` 注入,侵入性强且部分超出动态插件能力,留作 v2 独立目标。

## Considered Options

- **并存(选定)**:低风险、先拿到干净的网关闭环;代价是内置技能仍全量注入,上下文膨胀问题只对网关技能解决。
- **排他**:网关成为唯一技能通道,彻底解决膨胀;但推翻"v1 不碰现有技能"的边界,且需硬拦截 `skill` 工具与技能摘要注入。

## Consequences

- 未来若做 v2 排他,需重新论证并可能回退本决策。
- 统计子系统因"恒生效"需同时观测网关 `load` 与默认 `skill` 工具两种来源。
