# Skill Gateway 页面原型 v2（上传改版 + Agent 整理）

一个自包含的 DeepSeek Harness 插件页面原型，模拟右侧 **Skill Gateway 侧边栏**与 **DSH 整理会话**的完整工作流。视觉与组件严格遵循 `docs/style/deepseek/design.md`。

对应需求：`.scratch/skill-gate-organize/spec.md` 及其 issues（上传只收集技能、未分类分组、自动分类/一键整理/冲突检测会话、整理报告、快照回滚）。

## 运行

```bash
# 方式一：直接双击 prototype/version2/index.html
# 方式二：
python3 -m http.server 8000 --directory prototype/version2
# 浏览器打开 http://127.0.0.1:8000/
```

原型状态只存在内存里，刷新即重置；不读写真文件、不调用任何后端路由。整理会话的 Agent 行为为定时模拟（每步约 1s），可随时「打断整理」。

## 文件

```
prototype/version2/
  index.html   页面骨架与 DSH 外壳（会话列表 / 会话画布由 JS 动态渲染）
  styles.css   design.md 设计 token 与组件样式
  app.js       内联纯函数核心 + 交互逻辑 + 整理会话模拟
  README.md
```

## 覆盖的需求（新流程）

- **上传（仅收集技能）**：入口文案与弹窗为「上传」；递归扫描所选文件夹下含直接 `SKILL.md` 的文件夹为技能（整棵子树资源原样保留），文件夹层级不再创建/复用任何场景；任一技能 frontmatter 校验失败（缺 name / name 非法 / 缺 description / 无 frontmatter）则整体拒绝并逐条给出原因；同名技能原地覆盖（保留 createdAt 与使用历史）；技能文件夹之外的散文件进入忽略清单。
- **未分类分组**：上传后技能处于未分类状态，落盘即出现在「未分类技能」分组（与场景树同屏可见），可预览文件、可手动挂载到任意场景；解链 / 删场景后技能回到该分组；网关 browse/find 只遍历场景挂载，未分类技能天然不可见（网关取用 tab 有说明）。
- **整理会话机制**：上传成功后自动开启「自动分类」整理会话（固定命名「技能整理 #MM-DD HH:mm」）；会话以独立顶层会话出现在左侧栏「整理会话」分组，带状态徽标（整理中/已完成/已打断）；会话画布展示系统注入的整理提示词（完整场景摘要 + 未分类列表，不嵌入技能全文）与 Agent 逐步的工具调用（`skill_gateway` browse/load 深读、`skill_organize` 建场景/挂载/解链/移动/删场景/补写描述）；同一时间只允许一个整理会话，运行中其余触发被拒。
- **一键整理 / 冲突检测**：场景树页头部两个入口；一键整理 = 打整理槽位快照 + 整树整理会话（收拢过散挂载、移动技能、删除冗余场景、补写描述，并演示 `skill_organize` 对技能文件/描述只读、技能删除被拒的硬约束）；冲突检测 = 只读会话（不打快照、不改树），报告 ② 重复技能 / ③ 场景语义重叠 / ④ 挂载过散。
- **整理报告卡片**：最近一份报告（来源徽标 自动分类/一键整理/冲突检测 + 完成/已打断状态 + 改动摘要 + 冲突与重复清单 + 覆盖清单），无报告时给空态说明。
- **快照与回滚**：上传槽位与整理槽位各自独立、各保留最近一份；上传回滚 = 还原整树 + 删除本批新增技能文件 + 恢复被覆盖原文件；整理回滚 = 仅还原 catalog（不触碰技能文件）；回滚前确认弹窗明确提示「将还原到上传/整理前的整棵树」并列出受影响内容；回滚后视图刷新、报告标记「已回滚」；整理会话进行中回滚入口禁用；冲突检测不产生快照。
- **其余保留**：场景树 CRUD（含多挂载、级联删除解链回未分类）、全部技能列表、网关取用（browse → load，load 记录 gateway 使用）、网关开关（OFF 卸下工具与提示词，统计观察器恒生效）、统计（会话内时间线 + 仓库级聚合 + 来源过滤）、数据落点（`.skillgate/`，含 `snapshots/` 槽位说明与迁移入口）。

## 设计规范落地

- 4px 基础栅格，主色 `#165DFF`，主色浅背景 `#E8F3FF`，主色渐变按钮。
- 成功 / 警告 / 错误辅助色与对应浅色徽章底。
- 中性色、字体栈、字号字重均按 `docs/style/deepseek/design.md` 定义为 CSS 变量。
- 组件规则：胶囊分段控件、卡片、侧边导航栏、表格、弹窗、表单校验、Toast（含操作按钮）、空状态、进度条、徽章。

## 原型边界

- 不实现 ADR-0001 的真实文件持久化、并发合并与换址迁移；只做界面状态演示。
- 整理会话为定时模拟：不调用真实 DSH RPC / `ctx.agents.create` / `shell.overlay`；提示词内容与工具调用形态按 spec 的会话机制与 API 契约呈现。
- 上传读取依赖浏览器 File API，大文件未做分片或占位处理。
- 不包含 `find` action；与当前 HEAD 的 `skill_gateway` 工具契约一致，仅提供 `browse` / `load`。
